# Expositiva Petrobras

Plataforma de entrada do projeto de **Avaliação de Impacto Ambiental (AIA)**: reúne em uma única superfície o grafo interativo de leitura relacional e os produtos publicados desenvolvidos durante a pesquisa.

## O que é

Uma landing page institucional que organiza, em um ponto único de acesso, o conjunto de entregas do projeto AIA — do mapeamento visual de áreas, termos e artigos até as aplicações publicadas em ambiente de produção.

## Produtos disponíveis

| # | Produto | Descrição | Ambiente |
|---|---|---|---|
| 00 | **Grafo interativo** | Mapa relacional interno entre grandes áreas, termos, artigos e áreas de aplicação. | Local |
| 01 | **Explorador AIA** | Visão geral de áreas, termos e pesquisas em avaliação de impacto ambiental. | Vercel |
| 02 | **AIA Insight** | Exploração documental com RAG, governança e rastreabilidade para consultas auditáveis. | Vercel |
| 03 | **POC Classificador AIA** | Protótipo publicado para experimentos de classificação ligados ao contexto de AIA. | Streamlit |

## Acesso

Os produtos publicados estão disponíveis diretamente nos cards da landing page. O grafo interativo é acessado pela própria plataforma como camada complementar de análise.

## Stack

- Next.js 16 · React 19 · Tailwind v4
- Cytoscape.js e React Flow para visualização do grafo
